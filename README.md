Make a teleporter with this recipe:
```
 G
GDG
 G 
 ```
G = Gold Ingot
D = Diamond

Use on a lodestone to set the teleporter's location. 

Eat the teleporter to teleport to its marked location.

You can rename lodestones in an anvil and the teleporter's name will update to `[Lodestone Name] Lodestone Teleporter`. A lodestone without a name will be named `Activated Lodestone Teleporter`.
